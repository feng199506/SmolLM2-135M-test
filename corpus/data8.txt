一、最终目标

目标不是达到官方最低门槛，也不是让某个局部实验形式上 PASS。

最终目标是：

在官方同一评估器、配对 seed、相同资源预算和官方推理环境下，做出可重复、统计可信、具有实际幅度的分数提升；不增加失败、安全或稳定性风险，不以牺牲其他地图换取局部提升，并以足够分差超过当前冠军。

基准分为两层：

UID235：历史冻结基线、诊断基线和一键回滚对象。
UID20/v00：当前用户观察到的新冠军，经过 P9 验证后应成为候选新开发/竞争基线。

新冠军出现后：

不删除 UID235 历史实验；
不把 UID235 的提升直接视为对 UID20 的提升；
后续新策略优先在验证后的当前冠军基线上实验；
最终目标随当前冠军刷新，而不是固定为“UID235 +0.01”。

外部模型、跨任务代码、论文、GitHub、Discord、SLAM 等都只是候选机制来源，不能直接成为升级许可。

五、策略三层结构
1. 短期策略

特点：

数小时内可以实现；
不需要大规模训练；
使用现有 depth/state；
默认关闭；
可单模块 A/B；
容易回滚。

当前候选：

新冠军基线
UID20/v00 artifact 验证；
最小 instrumentation equivalence；
小规模分层基线；
替换 UID235 成为开发基准。
Mountain 路线边界

先测量：

waypoint 是否越过实际 world；
75/118/120m 边界冲突；
越界是否对应 TIMEOUT/低分。

有证据后才做条件 clamp。

Median pad refinement

使用多个检测的中位数稳定 pad 位置，重点验证 mountain noisy detection。

Orphan waypoint/lane redistribution

失败、完成或失联 drone 的路线/目标重新分配给有效 drone。

Boxed-only steering（SC2B）

当前结果：

六对 mean +0.0425；
median +0.0027；
CI [+0.00079,+0.0895]；
timeout +1；
collision −3。

状态：

PROMISING_SCORE_SIGNAL_BUT_FAILED_CURRENT_SAFETY_GATE

保持默认关闭，不调 keep=0.40，以后只在当前冠军基线上重新判断。

Spiral re-seed

路线耗尽、SEARCH 停滞后切换到未搜索方向，不再重复 clue-relative spiral。

Tilt-adaptive reference governor

高倾斜时限制激进动作，正常状态保持速度。必须同时评估速度损失。

Landing lock / commitment control

确认 pad 或进入 descent 后，减少目标切换和重新搜索。

Action-contract guard

阻止：

nonfinite；
错误 shape；
越界动作；
异常输出导致整条 seed 失败。

主要提高稳定性，不一定直接增加正常分数。

Thread pinning

与官方单线程匹配，减少延迟抖动和 strike 风险。

Fleet collision/separation

需要先区分：

teammate；
static obstacle；
failed drone；
descent/platform contact。

归因未解决前，不盲目扩大 separation radius。

Pad ownership与lane分配

包括：

claim；
release；
blacklist；
contention；
orphan takeover；
fleet-size-aware route capacity。
2. 中期策略

特点：

需要状态记忆；
可能需要小规模训练；
需要更多 development seeds；
开发成本中等。

候选：

Breadcrumb/visited-space memory

利用已有 _crumbs 或新建轻量历史：

避免重复搜索；
识别未覆盖方向；
为 route exhaustion 恢复提供依据。
Depth occupancy/local cost map

利用 depth + 已有位置：

局部障碍地图；
时间衰减；
短期空间记忆；
不重新做定位。
Receding-horizon route planning

根据：

当前 POS；
剩余时间；
新 depth；
visited-space；
teammate state；

有条件地重新规划，而不是一次性重复调用同一 clue-relative route head。

GoalPosterior/mass mountain 修复

加入：

time-to-go veto；
pad-found gate；
descent 禁止 replan；
expected-benefit 判断。

不能简单打开 mountain 开关。

更完善的平台分配

联合考虑：

距离；
到达时间；
pad 状态；
fleet size；
failed drones；
corridor capacity；
commitment。
失败阶段分类器

补齐：

SEARCH；
APPROACH；
COMMIT；
DESCENT；
collision partner；
pad contention。
小规模训练

包括：

mountain terrain classifier；
route head 微调；
pad detector refinement；
landing-state classifier。

训练成本高；

六、程序与推理优化线

训练阶段可以使用 GPU；正式推理必须严格服从官方 validator。

当前官方推理约束：

CPU-only；
2 CPU；
6GB；
有效单线程；
包大小限制；
不应依赖联网安装；
wall-clock 通常不直接进入分数，但影响 strike、失败和稳定性。
1. 优先的等价工程优化
模型只加载一次；
model.eval()；
torch.inference_mode()；
torch.set_num_threads(1)；
OMP_NUM_THREADS=1；
MKL_NUM_THREADS=1；
减少 NumPy/Tensor 复制；
避免重复 dtype、shape、normalization；
缓存静态 Tensor/mask/常量；
向量化 Python 循环；
PadNet 多 drone batch；
延迟加载非当前地图模型；
避免重复 import 和网络构建。

要求：

关键中间输出一致；
action-stream 一致或有严格误差界；
官方容器内验证；
N=2–8；
内存和延迟不恶化。
2. 中等风险优化
TorchScript；
ONNX Runtime CPU；
图优化；
算子融合；
模型文件加载优化。

需要检查：

动态 fleet N；
Transformer/自定义操作；
threshold 翻转；
detection/route/phase 差异；
官方依赖；
package size。
3. 高风险优化
INT8；
模型剪枝；
FP16 CPU；
跳帧；
降低输入分辨率；
detection threshold 调整；
改模型架构。

这些属于算法实验，不能称为无损程序优化。

4. 性能验证指标

必须记录：

初始化时间；
first-act p50/p95/p99；
steady-act p50/p95/p99；
最大延迟；
内存峰值；
RPC strike；
action equivalence；
N=2–8；
官方容器结果。
七、失败阶段树

后续 telemetry 应尽量区分：

far-from-target TIMEOUT；
near-target TIMEOUT；
SEARCH stagnation；
repeated search；
APPROACH failure；
COMMIT 未触发；
DESCENT collision；
DESCENT TILT；
teammate collision；
static-obstacle collision；
failed-drone obstruction；
pad contention。

原则：

策略必须匹配失败阶段。不能因为看到 TIMEOUT，就统一添加逃逸动作。

十、贝叶斯优化的位置

正确顺序：

提出机制
→ 小规模因果 A/B
→ 确认机制有效
→ development seeds 上调参
→ 冻结参数
→ validation
→ holdout/OOD
→ odd-N
→ 资源验证
→ promotion

适合优化：

route clamp；
boxed keep；
stagnation window；
spiral angle；
landing lock；
separation radius；
governor strength；
memory decay；
occupancy resolution。

禁止：

机制尚未有效就启动 BO；
用最终 holdout 调参；
用全部排行榜历史 seed 反复优化；
看结果后降低 promotion threshold。
十一、推广标准

初筛阳性不等于推广。

最终至少要求：

配对平均绝对提升 ≥ +0.01；
95% 配对 CI 下界 > 0；
同时满足当前官方 improvement floor；
以足够分差超过当前冠军；
overall failure 不增加；
目标地图改善；
非目标地图不超过预注册回退容忍度；
collision 不恶化；
TILT 不恶化；
TIMEOUT 不恶化；
官方 CPU/内存/包大小合规；
N=3/5/7 通过；
N=2/4/6/8 不出现 fleet-specific regression；
validation/holdout 后不再调参。

2–4 个 episode 只能做筛选。
